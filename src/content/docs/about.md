This site collects BMW coding guides that other people published. Nothing here is
original research.

## Read the source first

Every guide links the thread or documentation it came from. Open that link before you
touch the car. When a guide contradicts its source, trust the source. The guide has an
error, and you should report it.

## Check what a guide covers

Two things decide whether a guide applies to you.

### Match the car

A guide names the chassis code, build date, and head unit generation its source used.
Someone verified that procedure on one specific build. Yours may differ.

### Trust only quoted values

Module names, addresses, parameter names, and values come from the source, or they do
not appear at all. You will not find a value here that somebody guessed.

## Compare conflicting sources

Sometimes two sources describe the same job differently. Both go on the page, each
credited to whoever wrote it. Pick the one that matches your car.

:::caution
Coding changes control module settings. Read the module and save a backup before you
change anything.
:::

## Report a problem

Open an issue or a pull request against
[the bmwcoding.guide repository](https://github.com/SourceQuality/bmwcoding.guide).
Say which chassis and build date you have, and which source you worked from.
