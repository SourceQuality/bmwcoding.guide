This site collects BMW coding guides published by other people. Nothing here is
original research.

## Read the source

Every guide links the thread or documentation it came from. Open the source before
you code. If a guide and its source disagree, the source wins, and the guide is wrong.

## What guides record

A guide records the exact chassis, build, and head unit its source used. It does not
claim a procedure works on anything else.

### Vehicle details

Chassis code, build date, and head unit generation. A procedure verified on one build
is not assumed to work on another.

### Values

Module names, addresses, parameter names, and values come from the source or they do
not appear at all.

## When sources disagree

Both accounts appear, each attributed to its source. Pick the one that matches your
car.

:::caution
Coding changes control module settings. Read the module and save a backup before you
change anything.
:::

## Report a problem

Corrections go through the repository. Open an issue or a pull request against
[the bmwcoding.guide repository](https://github.com/SourceQuality/bmwcoding.guide).

Include your chassis, build date, and the source you are working from.
