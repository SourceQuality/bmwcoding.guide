BimmerUtility is a cross-platform coding application for BMW and MINI. You can run it as a standalone coding tool, or alongside E-Sys as an editor for FDL (function data) and FA (vehicle order) files.

The app talks to the car over ENET, BMW's Ethernet-based diagnostic connection. It runs on Windows PCs and on iOS and Android devices.

## Check vehicle support

The vendor lists support for BMW and MINI F, G, and I chassis cars. The license page also lists BMW motorcycles and Toyota Supra models.

Which coding options you get depends on the vehicle, its equipment, and its firmware level (iStep), according to the vendor's support page.

:::caution
The vendor states that the license cannot access secure coding 2.0 control units for FDL or VO (vehicle order) coding. Confirm that the modules you want to code are not secure coding 2.0 units before you buy a license.
:::

## Meet the system requirements

On Windows, the vendor requires a 64-bit system running Windows 7 SP1 or later, including Windows 8, 10, and 11. The vendor states that virtual machines and ARM processors are not supported.

On Android, the vendor requires Android 5 or later.

On iOS, the vendor's support page states iOS 8 or later. The App Store listing instead requires iOS 14.0 or later.

## Choose an adapter

BimmerUtility connects through the car's on-board diagnostics (OBD) port. The vendor's support page states that it only offers assistance for ENET cables and ENET Wi-Fi adapters, so other adapter types fall outside vendor support.

An ENET cable is a wired adapter that runs from the OBD port to your computer's Ethernet port. An ENET Wi-Fi adapter plugs into the same port and connects to your device wirelessly.

The vendor sells its own ENET Wi-Fi adapter. The vendor states that this adapter ships with a CAT-7 Ethernet cable for wired use and works with any ENET-compatible application. Check the [BimmerUtility adapter page](https://www.bimmerutility.com/adapter) for the current price.

## Install the app and buy a license

The App Store lists the iOS app as a free download. The vendor sells a single license that unlocks the app on both PC and mobile devices. Check the [BimmerUtility license page](https://www.bimmerutility.com/product-page/license) for the current price.

According to the vendor's home page, the license includes all features on every platform, File Cloud access, and lifetime free updates. The vendor's public pages do not document the activation steps, so check the [BimmerUtility support page](https://www.bimmerutility.com/support) after purchase.

## Connect to the car

Plug the ENET cable or ENET Wi-Fi adapter into the OBD port. The port usually sits under the dashboard on the driver's side, near the footwell.

For a wired connection, run the cable from the OBD port to your computer's Ethernet port. For a Wi-Fi adapter, follow the vendor's instructions for your adapter, then open the app.

:::note
On Windows, the connection can show up as "Unidentified Network" in the network settings. That is normal for an ENET link and does not indicate a fault.
:::

The vendor's public pages do not document a required ignition state or any manual network settings. If the app does not find the car, ask on the [BimmerUtility support page](https://www.bimmerutility.com/support) rather than guessing at network values.
