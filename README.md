# BMW Coding Wiki

A crowd-sourced Docusaurus wiki for BMW coding guides, deployed to Cloudflare Pages.

## Quick Start

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Deploy

This site is deployed automatically via Cloudflare Workers. Push to `main` and Cloudflare will build and deploy the site.
