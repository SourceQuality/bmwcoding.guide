# G Series Overview

The G series is BMW's current generation platform, introduced starting in 2018. These vehicles use the MGU (Media/Head Unit Generation) infotainment system and are highly configurable through coding.

## Head Unit Generations

The head unit determines what coding options are available and which tool version you need.

### MGU (ID6/ID7)
- Found in: G20, G30, G05, G80, G82
- Operating system: Linux-based
- Display: 10.25" or 12.3" center screen
- E-Sys compatible, BimmerCode compatible

### MGU2 (ID8/ID9 — iDrive 8+)
- Found in: G70, G60, newer LCI models
- Operating system: Linux-based with curved display
- Display: 12.3" instrument + 14.9" center (curved)
- BimmerCode support varies; E-Sys requires newer PSdZData

## Identifying Your Chassis

1. **VIN decoder** — the 4th–8th characters of your VIN encode the model
2. **Vehicle menu** — iDrive → Settings → General → Legal/Vehicle data
3. **Door jamb sticker** — lists the model code

| Body Domain Controller | BDC | Lighting, locking, comfort |
| Digital Motor Electronics | DME | Engine management |
| Instrument Cluster | KOMBI | Gauges, digital speedo |
| Advanced Driver Assistance | KAFAS2 | Camera-based driver assist |
| Seat Module | SITZM | Seat memory, comfort features |
