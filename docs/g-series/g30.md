# G30 / G31 - 5 Series (2017-2023)

The G30 sedan and G31 Touring were some of the first G-series BMWs and have great coding support.

## Quick Facts

- **Production:** 2017-2023
- **Head unit:** MGU (ID6/ID7)
- **OBD port:** Driver's side footwell, standard location
- **Recommended tool:** BimmerCode or E-Sys

:::note
The 2024+ 5 Series uses the G60 platform with iDrive 8. See the G70/G60 section for those.
:::

## Popular Coding Changes

### Exterior

| Mod | Module | Tool | Difficulty |
|-----|--------|------|------------|
| [Ambient lighting customization](/docs/mods/ambient-lighting) | BDC | BimmerCode / E-Sys | Easy |
| Fold mirrors on lock | BDC | BimmerCode | Easy |
| Welcome light carpet (if equipped) | BDC | E-Sys | Easy |

| Mod | Module | Tool | Difficulty |
|-----|--------|------|------------|

## G30 LCI Notes (2020+)

- Updated headlights, new iDrive version, and revised BDC firmware
- Most pre-LCI coding changes still apply
- Ambient lighting options expanded on LCI models
- Live Cockpit Professional (larger digital cluster) opens up more display options

## Tips

- G30 and G32 (6 Series GT) share many modules, so most G30 coding applies to the G32 as well
- 530e plug-in hybrid has an additional BMS (battery management) module, but standard comfort coding is the same
