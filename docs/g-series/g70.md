# G70 - 7 Series (2023+)

The G70 is BMW's flagship sedan with iDrive 8 and the curved display as standard. It runs on the latest CLAR platform and uses newer modules than earlier G-series cars.

## Quick Facts

- **Production:** 2023+
- **Head unit:** MGU2 (ID8/ID9), curved display standard
- **OBD port:** Driver's side footwell
- **Recommended tools:** BimmerCode (limited support so far), E-Sys (requires up-to-date PSdZData)

:::note
The G70 uses newer firmware than earlier G-series models, and third-party tool support is still catching up. Always check that your tool version supports your car's build date before making changes.
:::

## Confirmed Working

| Mod | Module | Tool | Difficulty |
|-----|--------|------|------------|
| [Ambient lighting](/docs/mods/ambient-lighting) | BDC2 | BimmerCode / E-Sys | Easy |
| [Digital speedometer](/docs/mods/digital-speedometer) | KOMBI | BimmerCode | Easy |
| Fold mirrors on lock | BDC2 | BimmerCode | Easy |
| Welcome light / light carpet | BDC2 | E-Sys | Easy |

## Good to Know

- The G70 uses **BDC2** (second-gen Body Domain Controller) instead of the older BDC. Module paths are different from G20/G30/G05.
- Luxury features like automatic doors or crystal headlights are hardware-dependent. You can only code them if the physical option is installed.
- E-Sys needs a recent PSdZData version for the G70. If your data files are outdated, the modules won't show up.

## Also Applies To

The G70 platform is shared with:
- **G60** - 5 Series (2024+)
- **i5** - electric 5 Series
- **i7** - electric 7 Series (same chassis, different drivetrain modules)

Most BDC2 and HU_MGU2 coding from the G70 works on these models too.
