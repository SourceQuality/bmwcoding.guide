# G05 / G06 / G07 - X5, X6, X7

BMW's SUV lineup shares a common platform, so most coding changes work across all three.

## Quick Facts

| | G05 (X5) | G06 (X6) | G07 (X7) |
|---|---|---|---|
| **Production** | 2019+ | 2020+ | 2019+ |
| **Head unit** | MGU (ID7) | MGU (ID7) | MGU (ID7) |
| **LCI head unit** | MGU2 (ID8) | MGU2 (ID8) | MGU2 (ID8) |

## SUV-Specific Features

### Iconic Glow (Illuminated Kidney Grille)
If your car has the illuminated kidney grille, you can code it through the **BDC** module in E-Sys:
- Glow activation on unlock (welcome effect)
- Glow always on while driving
- Brightness adjustment

### Air Suspension (if equipped)
Cars with air suspension (standard on X7, optional on X5) can have ride height defaults changed through E-Sys.

:::caution
Air suspension coding affects vehicle dynamics. Only make changes you fully understand.
:::

## LCI Notes

The 2023+ LCI models for all three SUVs use iDrive 8 with the curved display. Check the [G Series Overview](/docs/g-series/overview) for head unit differences.
