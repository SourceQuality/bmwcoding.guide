# G20 / G21 - 3 Series (2019-2025)

The G20 sedan and G21 Touring are some of the most popular BMWs for coding thanks to the huge community and wide availability.

## Quick Facts

- **Production:** 2019-2025
- **Head unit:** MGU (ID6/ID7), ID8 on LCI (2023+)
- **OBD port:** Driver's side footwell, standard location
- **Recommended tool:** BimmerCode for easy stuff, E-Sys for full access

## G20 LCI Notes (2023+)

The LCI (facelift) models switched to iDrive 8 with the curved display. A few things to know:

- Head unit module changes from `HU_MGU` to `HU_MGU2`
- Some BimmerCode features may not be available yet on the LCI
- E-Sys needs updated PSdZData files for LCI modules
- Some FDL coding paths have changed compared to pre-LCI

## Tips

- The G20 shares a lot of modules with the G22 (4 Series Coupe) and G26 (4 Series Gran Coupe), so most coding changes work across all three
- M340i and 330i share the same BDC and HU modules
- Always note your I-level before coding (you can see it in E-Sys or BimmerCode)
